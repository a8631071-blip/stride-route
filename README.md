# 步跡（Stride Route）

「步跡」是一款 Android 運動軌跡與日常計步 App，可用於步行、跑步與騎乘紀錄。

## 主要功能

- GPS 運動路線記錄
- 距離、時間、速度與配速
- 步數記錄與日常計步
- 運動歷史紀錄
- 背景運動路線記錄
- Android Health Connect 步數整合

## Google Play

https://play.google.com/store/apps/details?id=com.app.strideroute

## 開發環境

- React Native
- Expo SDK 54
- TypeScript
- Android minSdk 26 / targetSdk 36
